BUDPRO BRANDING & SIGNS — ONE-PAGE WEBSITE

FILES
- index.html: page content and structure
- styles.css: layout, colours, responsive behaviour and visual design
- script.js: mobile navigation, service preselection and WhatsApp enquiry form
- assets/budpro-logo.jpg: supplied logo image
- assets/budpro-brand-reference.jpg: supplied service/brand reference image

PREVIEW LOCALLY
1. Keep the folder structure intact.
2. Open index.html in a modern browser. Internet access is needed for the optional Google Fonts; the page otherwise works without a build process.

PUBLISHING
Upload index.html, styles.css, script.js and the assets folder to the same directory on your web host. Do not upload only index.html: the CSS, JavaScript and images are separate files.

FUNCTIONAL NOTES
- The enquiry form opens WhatsApp with a prefilled message; the visitor must press Send in WhatsApp.
- No form details are stored on a server.
- Update the phone/email/service details in index.html and the WhatsApp number in script.js if the business details change.
- The supplied reference image includes older contact information. This website uses the newer contact details supplied in the chat: 084 740 7920, info@budpro.co.za and sales@budpro.co.za.
- The Level 1 B-BBEE and 25 years experience statements are based on information supplied by the client and should be verified before publication.
